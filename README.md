# DKshad0w.github.io

Personal site, published with [GitHub Pages](https://pages.github.com/) at
<https://dkshad0w.github.io/>.

## How it works

This is a user site: because the repository is named `DKshad0w.github.io`,
whatever is committed to the `main` branch's root is served at
`https://dkshad0w.github.io/`. There is no build step for plain HTML.

## Editing

1. Edit `index.html` (or add more HTML/CSS/JS files).
2. Commit and push to `main`:

   ```sh
   git add .
   git commit -m "Update site"
   git push
   ```

3. Changes appear at the live URL within a minute or two.

## Pages settings

Repository → **Settings** → **Pages** → *Build and deployment*:

- **Source:** Deploy from a branch
- **Branch:** `main` / `/ (root)`

If you ever switch to a Jekyll theme or a `docs/` folder, change the branch/path
here to match.
